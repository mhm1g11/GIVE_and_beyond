## Reporting convention

Each scenario should record the baseline, policy counterfactual, fuel/geography coverage, annual emissions pathway, uncertainty design, valuation parameters, simulation horizon, code version and validation results. Global benefits must be distinguished from effects geographically attributed to Germany or the EU.

See the [scenario chapter template](template.md). The example in the repository is synthetic, and must not be presented as an empirical result.
