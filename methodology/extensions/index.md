# Potential extensions

The following is a **research backlog**. None of these items should enter model totals until independently implemented, benchmarked and integrated with the existing damage modules without overlap.

| Candidate | Rationale | Current status |
| --- | --- | --- |
| Revised 2026 agriculture function | Updated crop-yield evidence and a revised agricultural damage function (Moore et al., 2026) | **Not included.** Original GIVE agriculture remains active |
| Ozone-related crop losses | Methane affects tropospheric ozone and therefore yields | Not implemented |
| Ozone cardiovascular mortality and morbidity | Broadens the health burden beyond the respiratory subset | Not implemented |
| Heat-related morbidity | Potential non-fatal health damages | Not implemented |
| Ecosystems and biodiversity | Potential welfare damages absent from the present framework | Exploratory only |
| Additional extreme-event impacts | Possible gaps in current damage functions | Exploratory only |

## Evaluation rubric

For each candidate, document the peer-reviewed damage relationship, climate or atmospheric input, geographies and time horizon, baseline adaptation, socioeconomic input, monetary valuation, potential overlap with GIVE, available code and exact replication target. Only then decide whether integration is justified.

Revised labour and agriculture science: [Moore et al. (2026)](https://doi.org/10.1038/s41558-026-02749-z). Ozone science: [McDuffie et al. (2023)](https://doi.org/10.1029/2023EF003853).
